## Isolation and reproduction

Use a local, nonproduction schema with the normal seeded priority/SLA policies. The helper refuses production/nonloopback database configuration. It wraps all fixture inserts and updates in the existing outer transaction; service transactions use savepoints on the same connection. Explicit role/category/SLA restorations are also verified during the journey. Graceful API shutdown precedes pool restoration/rollback, then post-rollback checks confirm generated users, tickets, notifications, refresh sessions and actor audits are absent. Dependent histories, KB rows and category/SLA changes roll back in that same transaction. AUTO_INCREMENT gaps may remain. Existing developer accounts/settings/history are preserved.

Start Vite from `client/` with `VITE_API_BASE_URL=http://localhost:5099/api/v1`, host localhost and port 5173. Start an isolated Chromium profile with remote debugging port 9226, then run from `client/`:

```powershell
node tests/adminWorkflow.cdp.mjs
```

The driver owns its fixture API on localhost:5099. Do not run against a production database or an existing signed-in browser profile. `KEYBOARD_CDP_PORT` can override the debugger port. The HTML entry reuses the actual App bootstrap under a test-only hash URL so F5 is supported.

This is automated headless browser integration, not a human-operated session or production deployment check. No live SMTP/Cloudinary traffic, saved export binaries, full PDF parser/visual inspection, exhaustive accessibility/contrast audit or whole-application E2E sign-off is claimed. One SQL connection/savepoints cannot certify simultaneous assignment races. Existing regression suites provide edge contracts without beginning the later dedicated phases. Expected 401 recovery and deliberately injected 500 failures are part of the test.
